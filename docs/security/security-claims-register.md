## Custody-language discipline (BP §18)

User-facing surfaces must use the typed custody vocabulary — self-custody, external custody, smart-account authority, multisignature authority, delegated authority, session key, approval, allowance, bridge deposit, staking, wrapping, watch-only — and must never state or imply that a token representation itself proves an off-chain legal right (see `docs/legal/legal-and-regulatory-issues.md`).

## Process

New claim ⇒ new row ⇒ operator/legal review before any external use. Changed architecture ⇒ re-review affected rows (list the rows in the ADR).
