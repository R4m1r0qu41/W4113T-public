# Threat Model — CipherLayer Wallet

**Version:** 0.7 (2026-07-20: re-audit fixes, ADR-021 §7 — T-27: lock request eagerly invalidates any pending Solana approval (lock → unlock → sign cannot resurrect a nonce; proven at the real vaultd IPC boundary); the Solana ceremony now runs the full `cipherlayer-types::state` lifecycle with every transition audited under one request id (simulation/risk recorded as `unknown`, broadcast audited at acceptance); non-loopback RPC requires TLS; residual made explicit: hostname inequality does not prove administrative independence of the two mainnet providers — operator-enforced, and colluding/shared-operator providers remain the stated cross-check residual) (2026-07-19: external adversarial audit fixes — T-27 hardened: unbuffered zeroizing tty read, lock gate over the Solana ceremony, fail-closed audit, single-use covers malformed input, mandatory mainnet cross-check provider for pre-broadcast genesis+blockhash attestation; residual-risk summary reconciled with the runtime-key external-signer exception) (2026-07-18: T-27 runtime ed25519 key exposure for the Solana external signer, scoped to the vaultd process, ADR-021; T-09 chain-identity note extended to pinned Solana genesis re-verification before signing) (2026-07-16: browser-connect v0.4 — typed_data/personal_message signing + rpc_query read-only proxy, ADR-019; T-09 mitigation extended to typed-data domain chainId, T-22 caps extended to rpc_query/message payloads) (2026-07-07: T-04/T-12 process split + trusted surface; T-18/T-19 transport v0.3 host attestation, ADR-013) · **Method:** STRIDE-informed threat register over the trust-boundary diagram (`../architecture/trust-boundaries.md`). **Assets:** A1 key material · A2 signing authority · A3 user funds/allowances · A4 transaction-intent integrity · A5 policy integrity · A6 audit-trail integrity · A7 chain-identity correctness · A8 user trust/decision quality · A9 privacy (address↔identity linkage).

**Attackers:** ATK1 malicious dapp/web content · ATK2 phishing operator · ATK3 malicious/compromised dependency (supply chain) · ATK4 local malware (user-level) · ATK5 malicious RPC provider · ATK6 malicious contract author · ATK7 compromised AI agent/advisory component · ATK8 malicious plugin/extension (future surfaces) · ATK9 insider/maintainer error · ATK10 network attacker.

## Residual-risk summary (prototype)

The prototype's honest posture: **it protects decision quality, not key custody.** Key custody risks (T-11, T-14) remain *accepted* in milestone 1 solely because only worthless, publicly-known Anvil dev keys may exist in the system (ADR-005). T-04 (process split, ADR-004) and T-12 (trusted surface tier v1, ADR-012) have since moved from `accepted-P` to `partial-P` — the structural mitigations now exist, with named residuals (hardware-backed keys; SEP/occlusion surface tier). Every remaining `accepted-P` row becomes a blocking requirement before any real key or real fund is permitted **via vault custody** — the vault still holds only worthless dev keys, and that boundary is unchanged.

The one deliberate exception is the **runtime-key external-signer path** (ADR-020 EVM, ADR-021 Solana): an operator-held real key enters process memory for the duration of a single human-gated ceremony and is wiped. That path does not use vault custody and is not covered by the sentence above; it is governed by its own controls (T-27 for Solana: process-boundary confinement, single-use approvals, facts binding, pre-broadcast identity cross-check, lock gate, fail-closed audit) with its own named residual (same-user memory reads, T-14 class), and is gated by a live operator ceremony on a worthless-key network plus an external adversarial audit before any real funds (ADR-021 Consequences).

## Standing mitigations (cross-cutting)

Deterministic policy in front of signing (tested) · mandatory USER_REVIEW (unskippable state) · unknown-stays-unknown evidence semantics (tested) · append-only audited lifecycle (tested) · pinned dependencies + SBOM path · local-first defaults · mocked boundaries labeled.
